DAYFLOW — ANDROID APP PACKAGE

For an installable home-screen app:
1. Upload all files in this folder to an HTTPS static host (GitHub Pages is one option).
2. Open the HTTPS URL in Chrome on Android.
3. Use Chrome menu > Install app or Add to Home screen.

Opening index.html directly from Downloads works as a website, but browsers generally block PWA installation and service workers from file:// URLs.

Entries are stored in localStorage on this device and are not uploaded to a server. Use Backup/Export regularly. Clearing browser data can erase records.
